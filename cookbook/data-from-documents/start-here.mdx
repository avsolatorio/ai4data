## Interpretation of the result

- A **Not yet** result in chapter 1 comes first: an inventory is a day of
  work and decides where to spend the rest.
- Chapters 2 and 3 depend on each other; a team can start with tables from
  the text layer (chapter 3, recipe 3.1) before any layout detection.
- Chapter 4 is the one not to skip: an extracted value that was never
  checked is a transcription, and the chapter's checks use what the
  document already offers.
