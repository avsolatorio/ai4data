About this page
The server fetches the record from the catalog's public API, converts it with the metadata-schemas adapter, detects the search language, runs the rule-based query understanding (places, years, population groups, data type) and checks them against the record. The model then reads the item-first input and writes a verdict and a short explanation. The default model does not use a retrieval score, so any record can be explained without a search engine. Nothing is stored.
